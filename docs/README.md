# 🤖 JobAgent

> AI Powered Career Assistant

JobAgent est un assistant intelligent de recherche d'emploi développé en Python.

Il permet de :

- 🔍 rechercher des offres d'emploi depuis plusieurs sources
- 🎯 calculer automatiquement un score de matching
- 📄 gérer plusieurs profils et CV
- ⭐ sauvegarder les offres intéressantes
- 📊 suivre ses candidatures
- 🤖 utiliser l'IA pour améliorer le matching

---

## Fonctionnalités

- Multi-profils
- Matching Engine
- Parsing PDF
- Dashboard Streamlit
- SQLite
- Historique
- Favoris
- IA (en cours)

---

## Technologies

- Python 3.13
- Streamlit
- SQLite
- Git
- GitHub
- Pytest

---

## Installation

```bash
git clone https://github.com/lrx94/JobAgent.git

cd JobAgent

python -m venv .venv

source .venv/bin/activate

pip install -r requirements.txt

streamlit run app.py
```
